# Bluetooth Retry Helper
مشروع أندرويد لتكرار **اختبار الاتصال** بجهاز مقترن مسبقًا، مع اختيار الجهاز وعدد المحاولات والفاصل الزمني.

مهم:
- الاقتران يتم يدويًا من إعدادات أندرويد؛ التطبيق لا يكرر نوافذ PIN ولا يلغي اقتران النظام آليًا.
- الكود يختبر Bluetooth SPP فقط. السماعات والساعات والسيارات غالبًا لا تدعم SPP، لذلك قد لا يصلح لها.
- البناء على GitHub Actions باستخدام JDK 17 وGradle 8.9: `gradle :app:assembleDebug --no-daemon`
